# Agent Keyboard 0.1.0 – neu seit Build 23

Nur mit Tests geprüft, noch auf keinem Gerät ausprobiert.

- Neu: Einstellungen → Diagnose → „Letztes Feld“. Fehlen irgendwo Vorschläge, Großschreibung oder
  Autokorrektur, zeigt die erste Karte für das zuletzt benutzte Feld oben in einem Satz, warum: z. B.
  „Die App verbietet Vorschläge in diesem Feld“, „Die Tastatur schaltet sie in Webfeldern von Firefox
  selbst ab“, „Für Spanisch ist kein Wörterbuch geladen“ oder „Zuletzt lag die Symbolleiste über den
  Vorschlägen“, samt Ausweg, wenn es einen gibt. Darunter App, Feldtyp, was die App erlaubt, Sprache
  und Wörterbuch, was die Tastatur selbst abgeschaltet hat und was die Leiste zuletzt zeigte.
  Bitte direkt danach einen Screenshot schicken (die Suche der Einstellungen zählt nicht als Feld).
  Nie Text aus dem Feld, nur im Speicher; in Passwortfeldern, Inkognito und bei gesperrtem Gerät
  merkt sich die Karte nichts.
